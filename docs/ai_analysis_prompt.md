# Prompt for AI analysis

Загрузи файл `model_benchmark_ai_report.md` и проанализируй результаты benchmark.

Важно: в отчёте нет автоматической оценки качества. Не выдумывай рейтинг только по скорости. Оцени модели по фактам:

1. Полнота ответа модели.
2. Выполнение инструкции.
3. Пригодность к запуску кода.
4. Наличие синтаксических ошибок.
5. Был ли ответ обрезан лимитом токенов (`hit_token_limit`).
6. Скорость генерации.
7. Стабильность по нескольким test case.
8. Пригодность для локального CPU coding agent в Cline/Roo Code.

Сделай:

- общий рейтинг моделей;
- лучшую основную модель;
- лучшую быструю модель;
- модель для сложных задач;
- модели, которые лучше удалить или не использовать;
- какие тесты стоит добавить дальше.
